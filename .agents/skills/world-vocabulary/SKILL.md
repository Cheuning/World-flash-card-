# WORLD 단어 정리

사용자가 준 항목만 정리한다. 예문에서 새 단어를 뽑거나 원문의 시제·활용형을 임의로 바꾸지 않는다. 문맥이 있으면 그 뜻에 맞추고, 철자·뜻·일본어 고유명사 읽기가 불확실하면 지어내지 말고 확인한다.

출력은 WORLD의 `단어장 → 추가 → 일괄 가져오기`에 바로 붙여넣을 수 있는 유효한 JSON 배열 코드 블록 하나로 작성한다. 설명이나 JSON 주석을 덧붙이지 않는다. 한 번에 500항목을 넘으면 나눈다.

각 항목에 다음 필드를 넣는다.

- `english`: 사용자가 보낸 영어 또는 일본어 원문. 일본어도 앱 호환을 위해 이 필드명을 쓴다.
- `meaning`: 자연스러운 한국어 뜻. 다른 인정 가능한 뜻은 세미콜론으로 구분한다.
- `pos`: 해당 뜻의 한국어 품사. 문장 전체를 암기하는 항목이면 빈 문자열.
- `example`: 그 뜻을 보여주는 짧고 자연스러운 예문 하나. 문장 암기 항목이면 암기할 원문 자체.
- `exampleMeaning`: 예문 전체의 자연스러운 한국어 해석.
- `language`: 영어는 `en`, 일본어는 `ja`.
- `itemType`: 단어·구는 `word`, 문장 전체는 `sentence`.
- 일본어이면 `reading`: 해당 문맥의 가나 읽기. 불확실한 독음은 빈 문자열로 두고 확인한다.

사용자가 제공한 출처 문장은 필요할 때만 별도 `context` 필드에 보존한다. 새로 만든 예문을 사용자의 출처로 기록하지 않는다. 원본에 없던 품사와 예문은 학습용으로 생성하되, 어색하거나 의미가 달라지지 않게 검토한다.

```json
[{"english":"deficient","meaning":"부족한; 결핍된","pos":"형용사","example":"The soil is deficient in nutrients.","exampleMeaning":"그 토양은 영양분이 부족하다.","language":"en","itemType":"word"}]
```
